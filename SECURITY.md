# Security

HomeView runs in your browser inside Home Assistant and only does what your Home Assistant user
is allowed to do. If you find a security problem (for example a way for a tile or a config to
run something it shouldn't), please **don't open a public issue**: use
[private vulnerability reporting](https://github.com/nexhenry/homeview/security/advisories/new)
instead. You'll get a reply as soon as possible.
